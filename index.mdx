# RouteStack 文档

RouteStack 是一个统一的大模型 API 网关。你可以把它理解为一个稳定的中转入口：应用侧只需要对接 RouteStack 的 API 地址，就可以根据账号权限调用不同供应商、不同价格层级的模型。

## 你可以用 RouteStack 做什么

- 使用统一的 API Base URL 调用多个模型供应商
- 在控制台创建和管理 API Key
- 查看请求日志、模型用量、Token 消耗和扣费记录
- 根据账号、分组或令牌控制可用模型
- 通过余额、倍率和分组折扣管理不同用户的使用成本

## 适合谁使用

- 需要一个稳定 API 入口的开发者
- 需要给团队成员分配模型权限的团队
- 需要统一查看模型调用、用量和扣费记录的管理员
- 需要同时接入多个模型供应商的产品方

## 常用入口

| 入口 | 地址 |
| --- | --- |
| 控制台 | `https://routestack.cn/console` |
| 文档 | `https://docs.routestack.cn` |
| API Base URL | `https://api.routestack.cn/v1` |
| 本地开发地址 | `http://127.0.0.1:3000/v1` |

<Note>
  如果你当前还没有正式域名，可以先使用平台首页展示的 Base URL 或本地地址进行调试。
</Note>

## 第一次使用

1. 登录 RouteStack 控制台
2. 进入 `控制台 -> 令牌管理`
3. 创建一个 API Key
4. 将原项目中的 OpenAI Base URL 改为 RouteStack 的 Base URL
5. 使用 `/v1/models` 或 `/v1/chat/completions` 测试请求

下一步建议先阅读 [快速开始](/quickstart)。
