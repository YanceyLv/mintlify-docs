# 快速开始

本页会带你完成一次最基础的 RouteStack 调用。

## 1. 创建 API Key

登录 RouteStack 后进入：

```text
控制台 -> 令牌管理
```

点击创建令牌，复制生成的 Key。请妥善保存，API Key 只应该提供给可信的服务端或开发环境。

## 2. 配置 Base URL

如果你原来使用 OpenAI 官方接口，通常配置类似：

```text
https://api.openai.com/v1
```

接入 RouteStack 后，将 Base URL 替换为：

```text
https://api.routestack.cn/v1
```

本地调试时可以使用：

```text
http://127.0.0.1:3000/v1
```

## 3. 查看可用模型

```bash
curl https://api.routestack.cn/v1/models \
  -H "Authorization: Bearer YOUR_ROUTESTACK_TOKEN"
```

如果返回模型列表，说明认证和基础连接已经正常。

## 4. 发送聊天请求

```bash
curl https://api.routestack.cn/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ROUTESTACK_TOKEN" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": "你好，RouteStack"
      }
    ]
  }'
```

## 5. 在控制台检查日志

请求完成后，进入：

```text
控制台 -> 使用日志
```

你可以看到请求时间、模型、渠道、消耗额度和请求状态。

## 常见接入方式

### OpenAI SDK

```js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.ROUTESTACK_API_KEY,
  baseURL: "https://api.routestack.cn/v1",
});

const completion = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [{ role: "user", content: "Hello RouteStack" }],
});

console.log(completion.choices[0].message.content);
```

### Python SDK

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_ROUTESTACK_TOKEN",
    base_url="https://api.routestack.cn/v1",
)

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello RouteStack"}],
)

print(response.choices[0].message.content)
```
