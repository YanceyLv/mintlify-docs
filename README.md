# RouteStack Docs Scaffold

This directory is a starter Mintlify documentation project for RouteStack.

## Suggested next steps

1. Create a GitHub repository named `routestack-docs`
2. Copy these files into that repository
3. Connect the repository in Mintlify onboarding
4. Preview the site with the Mintlify dashboard URL
5. Add the custom domain `docs.routestack.cn`
6. Update your main website links to point to the new docs domain

## Local preview

Install the Mintlify CLI:

```bash
npm i -g mint
```

Run the local preview:

```bash
mint dev
```

Then open:

```text
http://localhost:3000
```
